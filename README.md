# SPORT RISK ANALYST PRO

Первый прототип сервиса спортивного анализа.

## Архитектура MVP

- Telegram-бот — основной интерфейс первой версии.
- Python backend — обработка сообщений и бизнес-логика.
- OpenAI API — AI-анализ (ключ хранится только в secrets/env).
- Правила V10.4 — отдельный системный prompt, чтобы их можно было развивать независимо от кода.

## MVP-функции

1. `/start` — меню.
2. Пользователь отправляет матч обычным текстом.
3. Бот отвечает предварительным анализом по V10.4.
4. На втором этапе пользователь может прислать скриншот линии.
5. Бот проверяет первоначальный рынок и выдаёт одну финальную ставку или ПРОПУСК.
6. Платные тарифы и лимиты подготовлены как следующий слой продукта.

## Запуск

Переменные окружения:

```text
OPENAI_API_KEY=...
TELEGRAM_BOT_TOKEN=...
OPENAI_MODEL=gpt-5-mini
```

Запуск:

```bash
pip install -r requirements.txt
python bot.py
```

**Никогда не помещай API-ключи в Git.**

## Важно

Сервис является информационным аналитическим инструментом, а не гарантией результата. Он не размещает ставки от имени пользователя и не использует догон/мартингейл.
